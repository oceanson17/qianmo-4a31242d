# 青阡

秦漢村野風大型單機手機 Safari 遊戲：星露谷式田莊生活 × 《青畦》AUTO × 《青囊·秦心》式 AI 對白。

- **網址**：見 GitHub Pages（本 repo）
- **存檔鍵**：`qianmo_v1`（瀏覽器 localStorage）
- **設定鍵**：`qianmo_settings_v1`（API Key 只存本機）

## v1 可玩內容

1. **選職業開局**：農夫／醫者／商賈／武卒／書生（銀兩、技能、起始差事不同）
2. **場景**：田莊｜村落｜坊市｜藥廬｜校場｜山野
3. **田莊**：點畦播／澆／收；方針；**AUTO** 自動種田賣糧過日
4. **戰鬥**：校場對練、山野爬層；AUTO 作戰；裝備白→金掉落
5. **對白**：鄉鄰 說／指令；有 DeepSeek 等 Key 則 AI，否則離線劇本＋記憶 stub
6. **設定**：供應商 DeepSeek／xAI／OpenAI／OpenRouter／自訂；chat／reasoner
7. **好感** 3 位鄉鄰、每日日令、工坊／藥廬配方
8. 手機約 420×912；系統字體；攔截 `weixin://`

## AUTO

畫面任一 **AUTO** 掣開關。依當前場景：

- 田莊：播、澆、收、賣、偶爾擴田與過日
- 村落：交日令、送禮
- 坊市／藥廬：製作、採藥
- 校場／山野：自動進戰、低血服藥、攻擊

## AI 對白用法

1. 標題或選單 → **設定**
2. 選 DeepSeek（預設），貼上 API Key，勾「啟用 AI 對白」
3. 可按「試連線」
4. 村落選鄉鄰 → **對白** → 切換「說」或「指令」→ 送出  
無 Key 或失敗時自動改離線回覆。
