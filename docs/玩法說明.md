## 1. 遊戲簡介

《墨夢莊周》是一套以 **秦王政元年**（少年嬴政剛即位、呂不韋為相邦）為背景的國風 **種田／人脈／副本／勢力** 文字 RPG。

你可在鄉野田莊耕織買賣，也可走進咸陽宮城、相邦府、邊關關市；過日會推演天下編年。開局可選：

- **史實軌道**：天下依史摘要推演，你仍可在關鍵事件中 **改史**。
- **高度自由**：史實權重較低，世界更多隨你與隨機動向推動。

玩法主軸：**種田賺銀 → 坊市人脈 → 探索打怪換裝備 → 入勢力／過劇情 → 完成差事領獎**。亦可開 **AUTO** 自動耕戰。

## 2. 開始遊戲

標題畫面可：

| 選項 | 說明 |
|------|------|
| **開始新局** | 先寫身世，再擇業 |
| **續寫** | 讀取本機存檔（有存檔才顯示） |
| **設定** | AI 對白等（見第 9 節） |

### 2.1 身世

- **姓名**（最多 8 字）
- **性別**：男／女／不顯  
  - 選「女」時可勾選 **女扮男裝**（易入禁地，有識破風險；遊戲中亦可於選單切換）
- **出身**（影響開局銀糧、技能、民心等微調）：
  - 農家、士族、商戶、軍戶、醫門、客籍、罪謫後人
- **志向**（可空，例如富甲一方／效力王廷／改寫命運）
- **世界模式**：史實軌道／高度自由

### 2.2 擇業開局

八種職業，各有起始銀兩、存糧、體力（HP）、攻防、技能與開局差事：

| 職業 | 特色摘要 |
|------|----------|
| **農夫** | 糧種充裕、農藝高；差事：收成稻 6 束 |
| **醫者** | 藥術與草藥；差事：煉成回春散 2 帖 |
| **商賈** | 銀兩厚、買賣利；差事：累計賣出得銀 80 |
| **武卒** | 身強力壯，開局桐木劍；差事：戰勝 3 場 |
| **書生** | 鄉鄰好感較易升；差事：任一人好感達 30 |
| **工匠** | 鍛礦製器，開局帶礦；差事：持有礦石 8 |
| **獵戶** | 擅入山，開局獵弓；差事：戰勝 4 場 |
| **遊俠** | 戰力與名聲並重；差事：邊塞最深達 3 |

開局另會贈若干農器／凡品，並依職業再贈一件良品裝備。

## 3. 核心循環

### 3.1 頂欄狀態

- **日期／季節／時辰**：春夏秋冬；一日內有 **晨、午、暮、夜**（28 日為一季，四季為一年）。
- **銀兩 ◎**、**存糧 ✿**、**名聲**、**民心**
- **飽／體／名／民** 條：體力（HP）會因趕路、戰鬥、潛入等消耗；過低請回 **陋室** 歇息。
- **屬性**：武、護、身、智、辯、運（含裝備加成，影響劇情選項門檻）
- **勢力標記**：未入黨顯示「獨」，入黨後顯示所屬簡稱

### 3.2 種田（田莊）

- 田格可種 **稻、菜、花、麥**（成長日數、是否需澆水、售價與轉存糧各異）。
- 可僱 **長工**（有上限與遞增工錢），場景上會有小人沿路走動。
- AUTO 方針可選：多種糧／多賺錢／擴田優先／存糧過冬。

### 3.3 坊市（市井）

- 買賣種子、糧、草藥、花、礦、回春散等。
- 累計賣出銀兩會記入帳冊，影響差事與名聲。

### 3.4 體力與過日

- **地圖趕路**會耗體力（各地成本不同；田莊／陋室為 0）。
- **陋室**：免費歇息回體；體力過低時地圖會提醒先回家。
- 園林閒步、水塘洗濯等亦可回復體力。
- **過日**：推進日期、季節與天下編年；過日後人物會依晨午暮夜在各地出現。

### 3.5 AUTO

對白區與各場景面板的 **AUTO** 可自動種田、買賣、採集或作戰（視當前場景）。戰鬥中可「結束戰鬥／逃回」以免卡住；陋室等目的地可強制脫戰。

### 3.6 底欄快捷

| 按鈕 | 用途 |
|------|------|
| **地圖** | 秦都與邊野輿圖，點 pin 前往 |
| **行囊** | 道具、裝備穿脫 |
| **人脈** | 鄉鄰／秦人列表，對白與送禮 |
| **差事** | 主線／支線／日常，完成後 **領獎** |
| **選單** | 存檔、天下大勢、結局冊、設定、回標題 |

## 4. 地圖與場景

地圖以俯視像素／山居風格場景圖呈現。地點類型大致如下：

### 4.1 鄉野日常

陋室、田莊、村落、市井、藥廬、園林、水塘、夜宴、驛道、酒肆、書塾、祠廟、庭院、祈願樹、霜柿山居、云海茶寮、品茗室、雨亭茶寮、聽雨廬、長橋、雙龍橋、水榭園、胡楊洲……

### 4.2 工坊百業

鐵鋪、木作坊、香鋪、織坊、書齋、紙坊、染坊、酒坊、藥鋪、漕幫碼頭、漕幫總壇、層田、鐵盟坊、觀星隱廬、浣劍居、墨池齋……

### 4.3 秦廷與關隘

咸陽、宮城外、相邦府、太后宮外、國尉府、客館、關市、河津、軍營、邊關。

其中 **宮城外、相邦府、太后宮外、國尉府、軍營** 為禁地，需過門檻才可進入（見第 6 節）。

### 4.4 探索／副本向

校場、山野、礦坑、廢墟、古墓、澤地、**雲縫谷**、石林等——可深入層數、打怪、挑戰 Boss。

## 5. 戰鬥、副本與裝備

### 5.1 戰鬥場景

校場練手、山野／邊關／礦坑深入、廢墟／古墓／澤地／雲縫谷／石林等皆可開戰。層數愈深敵愈強；可 AUTO 自動作戰。戰勝場數會累計；部分掉落裝備與材料。

### 5.2 Boss（部分）

| 地點 | Boss |
|------|------|
| 廢墟 | 廢墟魁首·石將軍 |
| 古墓 | 鎮墓獸·玄獒 |
| 澤地 | 澤中巨物·黿王 |
| 礦坑 | 礦脈主·岩魔 |
| 山野 | 山君·蒼獠王 |
| 邊關 | 邊關妖物·狼吞 |
| 雲縫谷 | 縫底炎魔·赭瞳 |
| 石林 | 石林石精·巖翁 |

擊敗 Boss 會記入探索紀錄，並可解鎖相關差事／相識遊俠等。

### 5.3 裝備

- **槽位**：兵器、甲胄、配飾（農器多掛於工具／配飾邏輯）。
- **稀有度**：凡 → 良 → 珍 → 史 → 傳說。
- **屬性**：武力、護體、身法、智計、辯才、氣運；並兼容攻／防／命。
- 於 **行囊** 裝備或卸下；頂欄「屬」會顯示合計。

六維屬性不足時，劇情選項會顯示 🔒 與需求提示。

## 6. NPC 好感、互動與門禁

### 6.1 相識與人脈

- 開局已識部分鄉鄰（何伯、蘇娘、趙三郎、林嫂、伍叔、成郎等）。
- 秦廷／六國／邊市等角色多需 **到訪場景或完成差事** 才「相識」；未識時人脈顯示「？？？」。

### 6.2 互動

- **對白**：人脈面板或場景遇人後開啟；可打字自由說，或選指令。
- **送禮**：依對方喜好加成不同；提升好感，並影響情感（敬意、畏懼、疑心、感激等）。
- 書生開局好感較高；場景偶遇亦可加好感。

### 6.3 禁地門檻

進入宮城外、相邦府、太后宮外、國尉府、軍營時，可選：

1. **收買門衙**（耗銀；女扮男裝時銀與輕功門檻略降）
2. **輕功潛入**（需輕功等級與體力）
3. **麻醉迷倒**（需藥理與麻醉藥；藥廬可煉）
4. **出示通行證**（若已持有該地令牌／名刺）

成功後永久解鎖該地訪問，並可能相識該處人物。

## 7. 勢力與劇情

### 7.1 三方勢力

| 勢力 | 簡稱 | 傾向 |
|------|------|------|
| **呂黨** | 呂 | 相邦門客網；貨殖、遊說 |
| **王府／秦廷** | 秦 | 軍功、秩序、編戶 |
| **邊市盟** | 塞 | 互市、庇護流民 |

日常耕戰買賣會緩慢推移好感；聲名漸起時可能有 **來訪招募**。可加入一方，或保持獨立。加入後會有勢力差事與 AUTO 方針微調。

### 7.2 天下編年

選單 → **天下大勢**：可見紀年、史實／自由動向摘要。過日或 AUTO 會推進編年（如少年秦王即位、呂氏權傾、鄭國渠傳聞、太后宮暗湧、客卿議法等）。玩家重大選擇可標為 **史已改**。

### 7.3 屬性門檻劇情（示例）

過日達一定條件後可能觸發（一天最多推一個），選項常鎖屬性：

- 相邦府外夜圍（救／棄／賣呂不韋——改史核心）
- 太后宮外兵變影、渠議廷爭、客卿李斯說法
- 邊關夜襲、觀星異象、鐵盟試煉、長安君密信、澤地毒瘴等

### 7.4 結局冊

選單 → **結局冊**。達成條件後點亮，中途與遠途結局可並存記錄。例如：阡陌富戶、呂門清客、王府編外、邊市仲介、眾望所歸、稱王野心、墨夢隱退等（條件依銀兩、名聲、民心、戰功、入黨與否等）。

## 8. 差事任務與領獎

底欄 **差事** 開啟任務列表。類型含 **主線／支線／日常**，以及職業開局差事、勢力差事。

### 8.1 領獎方式

1. 達成條件後會 toast「差事完成／可領獎」。
2. 打開 **差事** 面板，在已完成項目上按 **領獎**。
3. 獎品可為：**銀兩、存糧、名聲、民心、背包道具**（如稻、花、礦、草藥等）。
4. 領過不會重領；舊存檔已完成者會視為已領，避免重複。

### 8.2 主線示例

初入咸陽、相邦門檻、太后宮外傳聞、鄭國渠工匠、六國客館、少年秦王一見……

### 8.3 支線／日常示例

義診施藥、邊市走私影、軍營比武、祠廟祈福、麻藥初成、亭驛風聞、廢墟魁首、雲縫谷試煉、六維初成、陋室歇息；以及春耕首穫、庭院掃葉、云海一盞、水塘洗濯、靜坐燃香、書齋抄書、鐵鋪幫錘、漕運裝船、祈願掛籤、霜柿秋收、觀星問讖、園林閒步、鄉鄰好感、回春散成、聽雨一晝、坊市販售等。

完成部分差事還會 **相識** 新 NPC。

## 9. AI 與設定

標題或選單 → **設定 · AI**：

- **供應商**：DeepSeek／xAI／OpenAI／OpenRouter／自訂（OpenAI 相容）
- **模型**、可選 Base URL、**API Key**（只存瀏覽器 localStorage，不上傳）
- **啟用 AI 對白**：開則 NPC 對白可走線上模型；**關則用離線劇本**（無 Key 亦可玩）
- **試連線**：檢查設定是否可用

另有 **人物自主**（NPC 日程走動與簡易動態），不依賴 API Key。

存檔鍵為本機 `localStorage`（會自動遷移舊版存檔）。建議重要進度按對白區 **存檔** 或選單 **立即存檔**。

## 10. 操作提示（iPhone Safari）

1. **加入主畫面**：Safari 分享 →「加入主畫面」，全屏較穩。
2. **硬刷新**：若畫面仍是舊版圖／舊 UI，請用力重新載入（或清該站快取）後再開：  
   https://oceanson17.github.io/qianmo-4a31242d/
3. **安全區**：介面已預留瀏海／底部橫條 inset，底欄與對白區應不被擋住。
4. **體力見紅**：先點地圖 **陋室** 歇息，再遠行或打副本。
5. **戰鬥卡住**：用地圖「結束戰鬥」或逃回陋室／過日脫戰。
6. **差事紅點**：完成後記得開差事面板 **領獎**，獎品才會入袋。
7. **禁地進不去**：先賺銀、練輕功、藥廬煉麻醉，或女扮男裝降低門檻。
8. **想改史**：選史實軌道，提升六維與勢力好感，等待夜圍、渠議等事件出手。

## 小結：建議新手路線

1. 田莊耕種 → 市井賣貨，保住存糧與銀兩。  
2. 村落對白送禮，做「鄉鄰好感」「春耕」類日常差事並領獎。  
3. 藥廬煉藥、校場練手，再試山野／雲縫谷，換更好裝備。  
4. 湊銀與輕功／麻醉，嘗試相邦府、咸陽主線。  
5. 觀天下編年，決定入呂、入秦、通邊市，或獨善其身——走向自己的結局。
