## 3. 劇情系統（`story_flow.js`）

### 3.1 結構

- 模組全域：`window.QianStoryFlow`
- 節點表：`NODES`（約 40+ 個 `nodeId`）
- 狀態：`S.storyFlow = { nodeId, seen, started }`
- 旗標：`S.flags.*`、`S.plotFlags.*`、好感 `aff:npcId`、門禁 `access.*`
- 時段推進：選項可設 `advance: 'period'` 或 `'day'`

主要章節流向（摘要）：

1. **序** `pro_01` → 夢境／傳聞 →  
2. **村章** `ch1_hub`：採藥、青廬、送信、坊市、休息；村支線入口  
3. **上路** `ch2_*`：赴咸陽（戰鬥／交談分支）  
4. **咸陽** `xy_hub`：太醫署、宮城外／門禁／入宮、相邦府、太后宮外、市井支線、靜候命運弧  

節點選項支援：`if`／`need` 條件、`set` 寫旗標、`reward`（銀／糧／好感／背包）、`to` 跳轉。

### 3.2 面板操作

- **點選項**：`applyChoice` → 套用獎勵與旗標 → 渲染下一節  
- **回顧**：劇情行緩衝（`storyLines`／面板歷史）  
- **存檔**：寫入 `localStorage`（見第 10 節）  
- **支線**：`QianStoryFlow.listSides(S)` → `#sheet-side` 列表；可點 `jumpTo(nodeId)`（v45 修復「按了沒反應」）

### 3.3 命運弧（`arcs.js`）

獨立於節點短篇的「深談／來訪」弧，共 **7** 條：

| id | 標題 |
|----|------|
| `arc_ying` | 少年秦王·夜問邊野 |
| `arc_lu` | 相邦呂氏·奇貨之外 |
| `arc_zhaoji` | 宮闈·太后眉目 |
| `arc_lisi` | 客卿李斯·法術勢 |
| `arc_meng` | 邊將蒙恬·塞上約 |
| `arc_su` | 藥廬蘇娘·湯火緣 |
| `arc_cheng` | 書生成郎·志與情 |

觸發條件看名望、近側行跡、門禁、好感等；咸陽 hub 可「靜候命運來訪」。進度在 `S.arcProg`。

## 4. 自由輸入「想說／想做」（`free_act.js` + `ai.js`）

劇情面板 `#story-free`：

- 模式：**想說**／**想做**（`freeActMode`）
- 輸入最長 160 字 → `QianFreeAct.resolve(S, text, mode)`

### 4.1 推進邏輯（摘要）

1. 解析意圖（送禮、賄絡、潛入、請安、試探、邀約、告辭等）  
2. **優先對上當前節點可見選項**（`choiceId`）→ 等同點該選項  
3. 否則可 **`jumpTo`** 既有節點（如 `xy_palace_gate`、`side_vil_grain`、`xy_taiyi`…）  
4. 寫輕量 `sets`／`aff`／`advance`；計數 `plotFlags.free_actions`  
5. 自由行動累積後可叩命運弧檢查  

### 4.2 NPC 行動類型

`npcAction.type`（有標籤與狀態副作用）：

| type | 標籤 | 典型效果 |
|------|------|----------|
| `leave` | 離去 | NPC 退去 |
| `gift` | 回贈 | 好感／小物／銀 |
| `follow` | 願隨 | `S.followers`、following |
| `open_gate` | 開門放行 | 可通 `access.palace` 等 |
| `attack` | 拔刃相對 | 敵意／戰鬥傾向 |
| `invite` | 邀約同行 | `flags.invited_by` |
| `schedule_meet` | 約期再見 | 約定日後再遇 |
| `none` | 無行動 | 僅對白 |

### 4.3 AI 與離線

- **有 Key**（設定裡配置）：`QianAI.freeAct(ctx)` 回 JSON（旁白、對白、行動、choiceId／jumpTo…）  
- **無 Key**：離線模板／關鍵字意圖（`free_act.js`），反應偏固定但仍可跳節點、改旗標、觸發 NPC 行動  

出身／職業會影響意圖偏好（例如輸入「支線」時優先推相關 side 節點）。

## 6. 入宮／扮相

### 6.1 扮相

- 建角：女可勾「女扮男裝」；男可勾「男扮女裝」  
- 局中：陋室／行囊／選單 **「更衣扮相」**  
- 狀態：`S.hero.disguise` = `'male'`｜`'female'`｜`null`  
- 頭像：男扮女裝用女主臉；女扮男裝用職業男臉；存檔一併保存  

扮相影響門禁對白、識破風險（高懷疑／高好感時偶發），以及入宮選項可見性。

### 6.2 入宮門路（與舊「秦風」同思路）

入口：

- 輿圖 **宮城外**／劇情 `xy_palace` → `xy_palace_gate`  
- 咸陽 hub「設法入宮」  

`xy_palace_gate` 可選（條件滿足才顯示）：

| 方式 | 條件摘要 |
|------|----------|
| 收買門衙 | 銀 28 |
| 【商／客／塞等】薄賄 | 銀 18＋出身／職業 |
| 【細作／草莽】夜影潛入 | 耗體 |
| 男裝通融收買 | 銀 18＋`disguise===male` |
| 輕功潛入 | 身法／體力門檻 |
| 麻醉守卒 | 醫≥2＋麻醉藥×1 |
| （男裝）以男子之禮請見 | 女扮男裝 |
| （女裝）稱探后妃湯藥 | 男扮女裝（兼太后傳聞旗） |

成功設 `access.palace = true`，進入 `xy_palace_in`（打聽王位、投書、近側、太后宮外等）。

## 7. 閒務 AUTO（種田／打鐵／挖掘／副本）

底欄 **閒務** → `#sheet-idle`（v43 起；劇情頁已移除 AUTO）。

| 分類 `idleCat` | 對應場景 | 說明 |
|----------------|----------|------|
| `farm` | 田莊 | 稼穡；可設方針：多種糧／多賺錢／擴田／存糧過冬 |
| `forge` | 鐵鋪 | 鍛造 |
| `mine` | 礦坑 | 採掘 |
| `dungeon` | 可選地點 | 山野、校場、邊關、廢墟、古墓、澤地、雲縫谷、石林 |

控制：

- **AUTO**：`btn-idle-auto`；狀態文案「AUTO 開／關」  
- `idleAutoArmed`：由閒務啟動時鎖定該類，避免勢力偏好亂跳場景  
- **前往操作**：切到對應 mode 手動玩  
- **停止 AUTO**  
- 體力過低會傾向回陋室歇息  

場景層（`modes.js`）仍有大量 mode（茶寮、書塾、秦廷景點等）；AUTO 主循環在閒務四類。個別場景面板內可能仍殘留 AUTO 鈕，但產品意圖是 **主開關在閒務**。

## 10. 存檔／技術架構

### 10.1 前端架構

純靜態站，無後端遊戲伺服器。`index.html` 依序載入（皆 `?v=45`）：

```
modes.js → combat_data.js → equip.js → arcs.js → plots.js → ai.js
→ factions.js → world.js → story.js → workers.js → npc_ai.js
→ codex.js → story_flow.js → free_act.js → game.js
```

樣式：`style.css`（主）、`dash.css`。素材：`assets/`（webp 場景／立繪／UI）。

### 10.2 存檔

- 鍵：`qianmo_v4`  
- 內容：完整狀態物件 JSON（含 hero、career、flags、plotFlags、storyFlow、arcProg、bag、npcs、factions…）  
- 舊鍵自動遷移；`migrateSave` 補缺欄位  
- 劇情面板「存檔」與選單存讀；失敗 toast「存檔失敗」  

### 10.3 AI（可選）

設定頁配置 API；未配置則自由行動／對白走離線邏輯。AI 提示禁止抄錄現成小說、禁止寫死最終 `fate_*` 結局鍵。

### 10.4 部署

GitHub Pages 直接托管倉庫根目錄靜態檔；`.nojekyll` 避免 Jekyll 處理。改版後需硬刷新以清 cache（資源帶 `?v=45`）。

## 11. 已知限制

1. **自由輸入並非真正開放世界腳本**：只能對齊現有選項／白名單 `jumpTo` 節點與輕量旗標；不能生成全新章節圖。  
2. **無 AI Key 時**反應偏模板，推進力弱於有模型時。  
3. **支線／專屬選項**大量綁出身職業；不符條件會顯示鎖定，不是 bug。  
4. **舊存檔**可能缺 v45 新職業／出身欄位，遷移會填預設；**完整出身職業列表需新開一局**。  
5. **場景 AUTO 鈕**與閒務 AUTO 並存於 DOM；產品上主入口是閒務，舊場景鈕行為需以實測為準。  
6. **識破扮相**為機率／閾值事件，非完整潛行模擬。  
7. **靜態 Pages**：進度只在本機瀏覽器；清站資料或換裝置會丟檔（除非玩家自行匯出——目前以 localStorage 為主）。  
8. **內容體量**：主線節點與支線為中短篇網狀結構，命運弧有限；「極大自由度」體現在自由輸入＋多 lean 分支，而非無限生成劇情。  
9. **UI**：手機底欄與劇情 sheet 疊層曾出問題，v41+ 調整過；若仍異常需硬刷新或清 cache。  
10. **版權**：玩法可類近某類雙飛宮廷文遊體驗，但禁止／未實作任何原文搬運。
